# Project guide

Read [AGENTS.md](AGENTS.md) for architecture, language rules and verification commands. Read [docs/AUTOMATION.md](docs/AUTOMATION.md) before calling the importer.

The distributable is `plugin/glb_rig_importer.js`. The GLB decoder and track sampler are pure helpers; editor object creation and UI registration are adapter code. Documentation, examples, tests and repository assets live in separate directories.

All repository content must be in English. Publication and visibility changes require explicit maintainer authorization.
